# Security

CipherShield is a testnet prototype and has not been audited.

Security principles in the current frontend:

- client-side encryption before values leave the device
- encrypted contract state where supported
- authorized result decryption
- no fabricated wallet-derived risk/credit scores
- explicit testnet-only positioning

Do not use this repository with real funds until the contracts, SDK integration, permissions, and frontend have been independently reviewed and audited.
